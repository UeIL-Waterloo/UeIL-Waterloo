Using the visualizer

Add centre: choose 1s or a hybridization, select an available orbital, then Attach. Each 1s is an individual hydrogen centre; it is never added automatically. Yellow marks only your chosen hybrid.

+ LP / − LP: click an orbital to add or remove its two lone-pair dots. Adding a lone pair removes the terminal 1s attached to that orbital. Other electrons are not drawn. Undo restores the pair edit and the terminal together.

Remove centre: use Select to choose a centre, then click Remove centre beside the centre selector. Undo restores it.

Rotate: drag a centre about its σ axis. Drag empty space to rotate the scene. Reset view fits the structure with a main σ axis horizontal.

Each available orbital is assumed to contain one electron. Compatible overlaps form bonds automatically. A lone pair occupies an orbital and prevents it from bonding. π bonding requires in-phase side-by-side overlap and a distinct p orbital for each localized bond.

Shapes and overlap values are schematic, not calculated wavefunctions or bond strengths. Conjugation is not represented; benzene uses three localized π bonds. sp³d and sp³d² are idealized geometric teaching models.
