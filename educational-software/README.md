# Educational software

These are the original standalone HTML visualizers supplied by Germán Sciaini. They are copied without modification; each tool opens in its own tab from the website’s Educational software dropdown.

## Update a tool

Replace the matching HTML file in this folder and commit the change to GitHub. Keep these exact, case-sensitive filenames so the navigation links continue to work:

- Hydrogen_Orbital_Visualizer.html
- Hybrid_Orbital_Visualizer.html
- Molecular_Orbital_Visualizer.html

The tools contain their own styles and scripts. No build or package installation is needed. Do not paste the main website’s styles into them. Preserve their copyright notices and scientific explanations.

To add a fourth tool, put its HTML here and add its relative link to the education-dropdown in both ../index.html and ../publications.html. Open a tool locally by double-clicking its file, or serve the repository with python3 -m http.server 8000.

These supplied versions do not reference external script or stylesheet files. External scientific reference links may require internet access. The visualizer implementations have not been changed or revalidated scientifically during this website integration.
